## 七、验证流程（SOP）

1. **每日更新**：17:00 前由文档负责人刷新本文件（进度/风险/问题/决策）。
2. **负责人确认**：各模块任务完成后，负责人核对完成度与风险项。
3. **双人复核**：进度百分比、测试计数、里程碑日期为关键数据，需第二人交叉核对。
4. **门禁佐证**：任何进度声明须有对应门禁输出（tsc/test/build）佐证。
5. **检索优化**：本文件随文档中心索引（docs/README.md）发布，关键词可全文检索；里程碑/风险/决策均表格化便于可视化。
