# YYC³（YanYuCloudCube）-XY-公益课堂功能指南

## 📖 功能概述

公益课堂是小语AI应用的核心教育模块，为7-9岁儿童提供丰富多样的免费和付费在线课程。课程涵盖艺术创作、科学探索、编程思维、传统文化等多个领域，旨在培养儿童的综合素质和兴趣爱好。

## 🎯 核心功能

### 1. 课程分类浏览

- **全部课程**: 展示所有可用课程
- **我的学习**: 显示已报名课程及学习进度
- **收藏**: 查看收藏的课程

### 2. 课程筛选

- **分类筛选**: 9大课程类别
  - 🌟 全部
  - 🎨 艺术创作
  - 📚 阅读写作
  - 🔬 科学探索
  - 🎵 音乐舞蹈
  - 🌱 自然环保
  - 🏮 传统文化
  - 💻 编程思维
  - ⚽ 运动健康

### 3. 课程搜索

- 实时搜索功能
- 支持课程名称、教师、标签等多维度搜索

### 4. 课程详情展示

每个课程卡片包含：

- 课程缩略图和图标
- 课程标题和描述
- 课程类别和难度级别
- 授课教师信息
- 学习人数统计
- 课程时长
- 评分展示
- 免费/付费标识
- 新课/热门标签
- 课程标签
- 开始学习/继续学习按钮

### 5. 学习进度追踪

- 已报名课程显示学习进度条
- 进度百分比显示
- 一键继续学习

### 6. 热门推荐

- 首页展示热门推荐课程
- 精美的渐变背景设计
- 突出显示课程特色

### 7. 积分系统

- 学习积分实时显示
- 浮动积分徽章（右下角）

## 📱 技术实现

### 核心技术栈

- React + TypeScript
- Tailwind CSS
- Lucide Icons

### 组件结构

```
PublicClassPage
├── Header（顶部导航）
│   ├── 页面标题
│   ├── 筛选按钮
│   └── 搜索框
├── Tabs（选项卡）
│   ├── 全部课程
│   ├── 我的学习
│   └── 收藏
├── CategoryFilters（分类筛选）
├── CourseContent（课程内容）
│   ├── FeaturedCourse（热门推荐）
│   └── CourseGrid（课程网格）
└── FloatingStats（浮动积分）
```

```typescript
interface Course {
  id: string
  title: string
  category: string
  instructor: string
  students: number
  duration: string
  level: 'beginner' | 'intermediate' | 'advanced'
  rating: number
  isFree: boolean
  isNew: boolean
  isPopular: boolean
  description: string
  tags: string[]
  progress?: number
}
```
