# UI 设计方案 A — 柔和科技·温润精致

> 设计风格参考: Takram Design Engineering  
> 核心调性: 圆角柔影传递亲和力，数据图表如艺术品般克制，最适合婴幼儿类应用的温暖科技感

## 设计系统

### 色彩体系
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#10B981` (Emerald 500) | 品牌、CTA、活跃状态 |
| 主色浅 | `#D1FAE5` (Emerald 100) | 背景、卡片高亮 |
| 辅助色 | `#06B6D4` (Cyan 500) | 数据图表、链接 |
| 温暖色 | `#F59E0B` (Amber 500) | 徽章、里程碑 |
| 危险色 | `#EF4444` (Red 500) | 错误、异常 |
| 背景 | `#F9FAFB` (Gray 50) | 页面底色 |
| 卡片 | `#FFFFFF` | 卡片背景 |
| 文字主 | `#1F2937` (Gray 800) | 标题 |
| 文字次 | `#6B7280` (Gray 500) | 说明文字 |

### 字体
- 标题: "Noto Sans SC", 600/700 字重
- 正文: "Noto Sans SC", 400 字重
- 数字: "DM Sans", 500 字重

### 圆角与阴影
- 卡片: `border-radius: 20px; box-shadow: 0 4px 24px rgba(16,185,129,0.08)`
- 按钮: `border-radius: 12px`
- 头像: `border-radius: 50%`
- 输入框: `border-radius: 12px`

### 间距系统
8px 基数: 8/16/24/32/48/64

## 页面规划

### 首页
- 顶部: AI 小语浮窗 + 欢迎语 + 宝宝切换
- 统计卡: 学习天数 / 完成课程 / 获得成就 / 文化探索
- 快捷入口: 成长记录 / AI对话 / 今日任务 / 绘本阅读
- 今日推荐: AI 生成的内容卡片

### 成长记录页
- 成长曲线图 (WHO 标准百分位)
- 时间线 (里程碑 + 照片 + 文字)
- 快速记录按钮 (悬浮 FAB)

### AI 对话页
- 聊天界面 + 情感表情
- 语音输入按钮
- AI 角色切换

## 交互规范
- 页面切换: 左滑进入、右滑返回
- 卡片点击: scale(0.98) 缩放反馈
- 加载态: skeleton 骨架屏
- 动画: 200-300ms ease-out
