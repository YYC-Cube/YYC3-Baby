## 🚀 如何使用？

### 方法1：顶部快捷按钮
在首页顶部，你会看到三个彩色按钮：
- 📬 消息中心（蓝色）
- ❤️ 公益活动（红色）
- 📚 有声绘本（橙色）

**点一下，就能直接跳转！**

### 方法2：快捷功能卡片
首页下方有6个精美的功能卡片，点击即可访问对应页面。

### 方法3：底部导航栏
（如果你的版本支持）在屏幕底部有导航栏，可以快速切换页面。

## 💡 使用小贴士

### 📬 消息中心小技巧
- 黄色边框 = 作业反馈未读
- 紫色边框 = 系统通知未读
- 绿色边框 = 活动通知未读
- 点击"全部标为已读"可以清除所有未读标记

### 📚 有声绘本小技巧
- 左右滑动顶部的分类标签，查看不同类型
- 点击心形图标可以收藏喜欢的绘本
- 鼠标移到绘本封面上，会出现播放按钮
- 使用搜索功能快速找到想要的绘本

### ❤️ 公益活动小技巧
- 看看"正在进行"，参与最新活动
- 查看"历史回顾"，回顾你的公益历程
- 注意右下角的爱心值，这是你的公益成就！
- 有倒计时的活动要抓紧时间参加哦
