# 📖 YYC³ AI小语 · 家长使用手册

> 面向家长与家庭用户的简明操作指南。开发者文档见 [developer/](./developer/)，项目入口见 [README](../README.md)。

## 一、产品简介

YYC³ AI小语是一款**儿童成长陪伴平台**，围绕「记录 → 评估 → 陪伴 → 庆祝」四个环节，帮助家庭数字化记录孩子（小语）的成长轨迹，并通过 AI 提供个性化互动与建议。

## 二、快速上手

### 2.1 访问方式

| 方式 | 说明 |
| ---- | ---- |
| 网页版 | 浏览器打开部署地址（PWA，支持添加到桌面） |
| 桌面安装 | 右上角/右下角安装提示 → 「安装」，即可离线访问核心页面 |

### 2.2 首次使用

1. 打开首页，可先浏览「成长概览」与「今日推荐」。
2. 进入**我的/用户中心** → 注册或登录账号（用于多设备同步与写操作鉴权）。
3. 添加**孩子档案**（昵称、出生日期、性别），系统将按年龄/成长阶段定制内容。

## 三、核心功能地图

| 功能 | 入口 | 说明 |
| ---- | ---- | ---- |
| 成长记录 | 成长 → 记录 | 记录身高体重、里程碑、照片视频，支持语音输入 |
| 成长趋势 | 成长 → 数据可视化 | 生长曲线 / 能力雷达 / 活动分析 / 里程碑时间线 |
| AI 对话 | 小语对话 | 问答、绘本故事、情绪安抚（服务端密钥，无客户端泄漏） |
| 学习作业 | 作业 | 拍照上传 / 语音答题 / 文字输入，AI 智能批改 |
| 图书阅读 | 图书 | 绘本阅读器，支持沉浸模式 |
| 课程推荐 | 课程 | 基于年龄与性格的个性化课程与学习路径 |
| 徽章成就 | 徽章 | 30 枚勋章，基于真实行为数据自动评估 |
| 情绪陪伴 | 互动/情绪 | 情绪识别与安抚建议 |
| 生日主题 | 主题 | 生日倒计时、祝福墙、纪念相册 |

## 四、常见操作

### 4.1 记录一条成长

成长页 → 新建记录 → 选择类型（观察/里程碑/情绪等）→ 填写内容或拍照 → 保存。
系统会自动生成标签与标题建议（AI 分析）。

### 4.2 使用 AI 批改作业

作业页 → 拍照上传 → 系统识别并批改 → 查看错题分析与学习小贴士。

### 4.3 切换主题与无障碍

- 主题：主题切换器支持多套主题（含生日主题）。
- 无障碍：右下角无障碍入口可调节字体大小、高对比度、减少动画、屏幕阅读器等。

## 五、数据与隐私

- 数据存储于服务端 SQLite（`data/yyc3.db`），写操作需登录鉴权。
- 语音与 AI 请求均经服务端代理，API 密钥不进入浏览器。
- 桌面端支持离线访问（Service Worker 缓存核心资源）。

## 六、常见问题

| 问题 | 处理 |
| ---- | ---- |
| 记录无法保存 | 检查是否已登录（写操作需 Bearer 令牌） |
| 页面加载慢 | 网络弱时建议安装 PWA 使用缓存版本 |
| AI 无响应 | 确认服务端已配置 `BIGMODEL_API_KEY` 等密钥 |
| 忘记密码 | 联系管理员重置（当前版本无自助找回） |

## 七、反馈渠道

遇到问题可反馈至项目维护团队；生产环境会自动上报前端错误（`/api/error-report`），
管理员可在日志（`logs/`）中检索定位。
