## 方案一：AI 情感陪伴成长系统

### 核心理念
通过实时情感识别 + 上下文理解，让 AI 小语成为真正「懂孩子」的成长伙伴。

### 技术架构

```
语音/文本输入 → 情感识别引擎 → 上下文记忆 → AI 响应生成器 → 个性化回复
     ↓              ↓              ↓              ↓
  TensorFlow.js  情感模型     向量数据库     BigModel API
  (浏览器端)    (7种基础情感)  (Neo4j图谱)    (智谱GLM)
```

### 功能设计

| 功能 | 描述 | 数据流 |
|------|------|--------|
| **情感识别** | 通过文本/语音分析孩子当前情绪（开心/悲伤/愤怒/焦虑/平静/好奇/疲惫） | 输入→TensorFlow.js→情感标签 |
| **上下文记忆** | 基于知识图谱记住孩子的偏好、近期话题、成长阶段 | 对话→Neo4j→关系图→上下文注入 |
| **个性化回复** | 根据情感+年龄+偏好生成适合的回复（语气、复杂度、内容） | 情感+上下文→Prompt模板→BigModel→回复 |
| **成长建议** | 基于对话内容自动生成成长观察报告和活动建议 | 对话摘要→评估引擎→建议卡片 |

### 数据流详细设计

1. **输入层**: 用户通过文本/语音输入
2. **预处理**: 文本清洗 → 情感分析（emotion-engine.ts）
3. **上下文检索**: 从 Neo4j 查询近期对话主题、孩子兴趣点、成长里程碑
4. **Prompt 构建**: 情感标签 + 成长阶段 + 上下文 + 用户输入 → AI Prompt
5. **生成**: 调用 BigModel API（智谱GLM）
6. **后处理**: 安全过滤 → 语气调整 → 知识图谱更新
7. **输出**: 回复 + 情感表情 + 推荐活动

## 方案二：AI 智能成长分析与预测系统

### 核心理念
基于成长数据（身高/体重/里程碑/活动量）+ AI 分析，提供科学的成长洞察和预测。

### 技术架构

```
成长数据采集 → 数据标准化 → AI分析引擎 → 预测模型 → 可视化报告
     ↓              ↓            ↓           ↓          ↓
  手动/AIoT    WHO标准对齐   自适应集成   趋势预测   交互式图表
```

### 功能设计

| 功能 | 描述 | 技术实现 |
|------|------|---------|
| **成长曲线追踪** | 身高/体重/头围与WHO标准百分位对比 | Recharts + WHO数据 |
| **里程碑智能检测** | 基于年龄自动推荐应达到的里程碑，检测遗漏 | 规则引擎 + AI分析 |
| **异常预警** | 当数据偏离正常范围时主动提醒 | 统计异常检测 (Z-score) |
| **成长预测** | 基于历史数据预测未来3-6个月的成长趋势 | 自适应集成预测 (lib/prediction/) |
| **个性化建议** | 基于成长数据生成饮食/运动/学习建议 | AI分析+知识图谱 |

### 数据流设计

1. **数据采集**: 手动记录 + AI语音输入 + 照片AI识别
2. **标准化**: 转换为标准格式（单位、日期、参照系）
3. **WHO对齐**: 计算百分位（使用 WHO Child Growth Standards）
4. **趋势分析**: 短期（30天）/ 中期（90天）/ 长期（365天）
5. **异常检测**: Z-score > 2 或趋势突变
6. **AI洞察**: 调用 BigModel 生成自然语言洞察
7. **可视化**: Recharts 交互式图表 + AI洞察卡片
