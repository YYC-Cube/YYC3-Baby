# 小语AI应用 - 功能演示指南

## 🎯 演示目标

展示"小语AI应用"的三个全新核心功能页面，突出儿童友好设计和丰富的交互体验。

## 📋 演示流程

### 第一部分：首页导览（30秒）

#### 演示要点
1. **顶部导航栏**
   - 展示天气信息和日期
   - 指出三个新增功能入口：📬 消息中心、❤️ 公益活动、📚 有声绘本

2. **角色互动**
   - 展示小语角色形象
   - 显示友好的问候语

3. **快捷功能区**
   - 展示6个快捷功能卡片
   - 强调新增的三个功能卡片

#### 操作步骤
```
1. 启动应用，显示首页
2. 指向顶部三个彩色按钮
3. 滚动到快捷功能区
4. hover显示卡片效果
```

---

### 第二部分：消息中心（1分钟）

#### 演示要点
1. **页面布局**
   - 清晰的页面标题和图标
   - "全部标为已读" 功能按钮

2. **消息分类**
   - 作业反馈（2条未读）- 黄色系
   - 系统通知（1条未读）- 紫色系
   - 活动通知（0条未读）- 绿色系

3. **消息详情**
   - 未读消息的边框高亮效果
   - 时间戳显示（10分钟前、昨天、3天前）
   - 消息图标和内容

#### 操作步骤
```
1. 从首页点击 "消息中心" 按钮
2. 指出三种消息类型和未读数量
3. 展示未读消息的高亮边框
4. hover消息卡片显示交互效果
5. 点击 "全部标为已读" 按钮（演示用）
```

#### 演示话术
> "这是消息中心页面。孩子们可以看到三类消息：作业反馈、系统通知和活动通知。
> 未读消息有特殊的边框标识，非常醒目。
> 每条消息都有时间戳，让孩子知道消息是什么时候收到的。"

---

### 第三部分：有声绘本（1分30秒）

#### 演示要点
1. **搜索功能**
   - 顶部搜索栏
   - 返回按钮

2. **分类筛选**
   - 横向滚动的9个分类
   - 激活态的渐变效果
   - Emoji图标

3. **今日推荐**
   - 大卡片展示
   - 渐变背景
   - "开始阅读" 按钮

4. **绘本网格**
   - 2列布局
   - 收藏功能（红心图标）
   - AI绘本标签
   - hover显示播放按钮

#### 操作步骤
```
1. 从首页点击 "有声绘本" 按钮
2. 点击搜索栏（不输入内容）
3. 横向滑动分类标签
4. 点击不同分类，显示切换效果
5. 指向今日推荐大卡片
6. hover绘本卡片，显示播放按钮overlay
7. 点击收藏按钮（红心）
```

#### 演示话术
> "有声绘本页面提供了丰富的分类选择，包括故事、诗歌、情绪管理等9大类别。
> 首页有一个精美的'今日推荐'区域，展示当天推荐的绘本。
> 每本绘本都可以收藏，鼠标移上去会显示播放按钮。
> 所有绘本都有AI绘本的标签，表明这是由AI辅助创作的优质内容。"

---

### 第四部分：公益活动中心（1分30秒）

#### 演示要点
1. **Tab切换**
   - 正在进行（2个活动）
   - 历史回顾（5个活动）

2. **活动卡片（正在进行）**
   - "绿色小星球" - 绿色渐变
   - "故事伴读计划" - 蓝色渐变
   - 参与人数显示
   - 倒计时显示（绿色小星球）
   - 行动按钮

3. **活动卡片（历史）**
   - 半透明效果
   - 已结束状态标签
   - 爱心积分显示

4. **爱心值浮窗**
   - 右下角固定显示
   - 当前爱心值：500

#### 操作步骤
```
1. 从首页点击 "公益活动" 按钮
2. 展示 "正在进行" 的活动
3. 指出参与人数和倒计时
4. hover活动卡片显示效果
5. 点击 "历史回顾" Tab
6. 展示已完成的活动
7. 指出右下角的爱心值浮窗
```

#### 演示话术
> "公益活动中心让孩子们参与有意义的社会活动。
> 正在进行的活动有两个：'绿色小星球'线上种植和'故事伴读计划'。
> 每个活动都显示已有多少同学参与，还有倒计时提醒。
> 在历史回顾中，孩子们可以看到自己参与过的活动和获得的爱心积分。
> 右下角始终显示当前的爱心值，激励孩子们持续参与。"
