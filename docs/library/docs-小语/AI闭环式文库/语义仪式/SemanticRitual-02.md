## 🪞 团队文化演化图谱的视觉 DSL → .svg 输出

模块名：TeamEvolutionMotionDSL

代码

```plaintext

```

### ✅ DSL 数据结构

ts

```plaintext
type EvolutionMotionFrame = {
  timestamp: string // 如 '2025-Q4'
  member: string // 如 'Yu'
  philosophyTags: string[] // ['克制', '诗意']
  expressionStyle: string // 如 '结构表达'
  quote: string // 如 '表达是结构中的温度'
  modules: string[] // ['评分器', '镜像页']
  motion: string[] // ['fadeIn', 'float']
  color: string // '#F5CBA7'
}
```

### ✅ SVG 输出建议

- 每个成员为一条演化轨迹线
- 每个哲学标签为颜色节点
- 每个表达风格为图标或语录气泡
- 动效结构可用于路径动画（如 float → 曲线移动）

### ✅ 示例调用

ts

```plaintext
const dsl = new TeamEvolutionMotionDSL()
dsl.addFrame({
  timestamp: '2025-Q4',
  member: 'Yu',
  philosophyTags: ['克制', '诗意'],
  expressionStyle: '结构表达',
  quote: '表达是结构中的温度',
  modules: ['评分器'],
  motion: ['fadeIn', 'float'],
  color: '#F5CBA7'
})
dsl.exportToSVG('team-evolution.svg')
```
