## 🔐 访问权限说明

- **公开访问**: 无需登录即可访问
- **需要登录**: 需要用户认证
- **开发环境**: 仅在开发模式下可用

---

## 📝 注意事项

1. 所有页面都使用 Next.js App Router
2. 客户端组件使用 `"use client"` 指令
3. 使用 Framer Motion 实现动画效果
4. 集成了国际化支持（`[locale]` 路由）
5. 测试页面在生产环境中应被移除

---

## 🔄 路由规范

- 使用 kebab-case 命名路由
- 功能页面放在 `app/` 目录下
- 子功能使用嵌套路由（如 `/growth/assessment`）
- 测试页面统一添加 `-test` 后缀
